\# Excel Data Analysis Project – Sales Dashboard



\# Project Overview  

This project is an interactive Excel-based data analysis dashboard built using sales data. It focuses on transforming raw data into meaningful insights through data cleaning, Pivot Tables, Pivot Charts, and interactive slicers.



The main goal of this project is to analyze sales performance and present insights in a clear and interactive dashboard for better decision-making.





\##  Tools Used  

\- Microsoft Excel  

\- Pivot Tables  

\- Pivot Charts  

\- Slicers  

\- Data Cleaning \& Transformation  

\- Conditional Formatting  

\- KPI Metrics  



\# Project Features  



\### Data Cleaning  

\- Removed duplicates and blank values  

\- Standardized data formats (dates, categories, etc.)  

\- Handled missing or inconsistent data  



\###  Pivot Tables  

\- Sales by category and region  

\- Profit analysis by product  

\- Monthly performance trends  



\###  Dashboard  

\- Interactive Excel dashboard using Pivot Charts  

\- KPI indicators for:

&#x20; - Total Sales  

&#x20; - Total Profit  

&#x20; - Profit Margin  

&#x20; - Total Orders  



\###  Slicers \& Filters  

\- Region filter  

\- Category filter  

\- Time period filter  

\- Fully interactive dashboard for dynamic analysis  





\## Key Insights  

\- Identified top-performing product categories  

\- Highlighted high-revenue regions  

\- Analyzed monthly sales trends  

\- Identified products contributing most to profit  



\## 💡 What I Learned  

\- Advanced Excel data analysis techniques  

\- Building interactive dashboards  

\- Working with Pivot Tables and Pivot Charts  

\- Turning raw data into actionable insights
